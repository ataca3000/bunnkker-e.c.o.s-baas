## 2. Protección de Datos (Local-First)
ADMIN.COM opera bajo una filosofía de "Privacidad por Diseño":
- **Soberanía de Datos:** Cada instalación genera su propia base de datos local cifrada. Los datos de inventario, clientes y ventas pertenecen al licenciatario y residen en su hardware.
- **Aislamiento:** No existe una base de datos centralizada que comparta información entre distintos dueños de negocios.
- **Acceso Remoto:** La sincronización con la nube es opcional y requiere una suscripción activa a los servicios de enlace de BRECHA SOLUCIONES.
