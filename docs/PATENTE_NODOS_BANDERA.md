## 🏛️ 1. REIVINDICACIONES TÉCNICAS PURAS (PATENT CLAIMS)

### 🔹 Reivindicación 1: Arquitectura de Mini-Data Center Privado ("Nodo Perrito")
- **Autonomía Nodal In Situ:** Dispositivo físico compacto de bajo consumo energético que actúa como servidor maestro privado local (Self-Hosted Data Center), ejecutando el motor ERP y punto de venta sin depender de servidores en la nube de terceros.
- **Emisión de Servicios de Proximidad:** El nodo emite cobertura Wi-Fi local y balizas NFC para interacción directa con dispositivos de empleados y clientes a 0ms de latencia.

### 🔹 Reivindicación 2: Red Malla P2P Terrestre Inter-Compañía
- **Interconexión P2P Autónoma:** Red distribuida donde cada nodo ("Perrito") se enlaza con otros nodos de la red mediante los planes de transporte de red ya contratados por la compañía, formando una malla global descentralizada sin intermediarios ni puntos únicos de falla (SPOF).

### 🔹 Reivindicación 3: Sistema de Alimentación Dual Híbrida 24/7
- **Conmutación Diurna Solar / Nocturna Eléctrica:** Los nodos instalados en infraestructuras terrestres (postes de cuadras/barrios o locales) funcionan mediante fotoceldas solares durante las horas de luz del día y conmutan automáticamente a la red eléctrica pública durante la noche.

### 🔹 Reivindicación 4: Independencia Absoluta de Infraestructura Satelital
- **Aislamiento Terrestre:** Operación 100% confinada al plano terrestre. El sistema prescinde de enlaces orbitales, constelaciones satelitales o GPS espacial para la validación de transacciones y autenticación de usuarios.

### 🔹 Reivindicación 5: Soberanía de Datos y Puertas de Red Existentes
- **Resguardo Local Privado:** La base de datos vive exclusivamente en el hardware local. Los datos se comparten hacia el exterior **únicamente bajo demanda explícita** utilizando las puertas de pago y APIs comerciales contratadas (Stripe, MercadoPago, SAT 4.0).
