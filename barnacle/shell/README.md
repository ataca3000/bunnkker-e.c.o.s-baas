# Barnacle CLI - Docker Freemium Shell

CLI para configurar y publicar contenedores con monetización Barnacle.

## Comandos

- `barnacle init` - Inicializar configuración freemium
- `barnacle config --price X --trial-days Y` - Configurar precio y período de prueba
- `barnacle publish` - Publicar imagen a Docker Hub con Barnacle
- `barnacle validate` - Validar configuración
