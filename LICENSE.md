## ESTRUCTURA DE LA LICENCIA DUAL

Este repositorio contiene dos partes que viven juntas en armonía ("son uno solo"), pero se rigen por reglas distintas para proteger tanto a los creadores del núcleo como a los creadores independientes de plantillas.

### 1. EL MOTOR CENTRAL (Licencia Comercial Restringida)
**Aplica a:** La arquitectura base, bases de datos, APIs (`/src/app/api`), sistema de encriptación, middleware (`src/middleware.ts`) y lógica de Multi-Tenant.
- **Autoría:** El código de este motor es propiedad intelectual de **Brecha Soluciones S.A. de C.V.** y su autor (anónimo por diseño). No buscamos fama ni culto a la personalidad, buscamos trabajo digno.
- **Prohibición:** Queda estrictamente prohibido clonar, revender, apropiarse o extraer esta lógica central para crear un software competidor o venderla bajo otro nombre. 
- **Uso:** El acceso a este motor se obtiene pagando la suscripción justa. Las grandes corporaciones no tienen derecho a robar el esfuerzo de arquitectura detrás de este código.

### 2. ECOSISTEMA DE PLANTILLAS Y UI (Licencia Libre para Creadores)
**Aplica a:** Diseños visuales, componentes de interfaz (`/src/components`), CSS y páginas front-end.
- **Libertad Total:** Eres libre de usar nuestro Framework Visual para diseñar plantillas para restaurantes, ferreterías, clínicas o lo que se te venga en gana.
- **Economía Justa:** Puedes vender las plantillas que tú diseñes a tus propios clientes al precio que tú decidas. **Conservas el 100% de tus ganancias.**
- **Crédito:** Nadie te va a dejar fuera. Tu trabajo es tuyo. Lo único que necesita tu cliente para usar tu diseño es pagar la suscripción del Motor Central.
